# Privacy Policy

Mixhive is designed to be local-first unless explicitly documented otherwise.

## Data Collection

This project does not intentionally collect personal data by default.

If hosted services, telemetry, payments, or cloud integrations are added, this
policy must be updated before release.

## Payments

Payments are handled through Stripe. Do not send payment card information
through GitHub Issues, email, chat, or support tickets.

## Local Secrets

API keys and credentials must be stored in secret managers or environment
variables, never in source-controlled files.

## Contact

Privacy contact: privacy@mixhive.dev

Legal review required before public commercial launch.
